# Joy's portfolio

Hi! I'm Joy, and I studied the Webmaster program at University West in Sweden. This is a collection of my school projects in web development.

## Projects

### [StudioYoga](https://joystromer.github.io/portfolio/StudioYoga/index.html#/)

A yoga app built with React and Vite, using an open API to show yoga poses for three levels.

### [HelenaStromerArt](https://joystromer.github.io/portfolio/HelenaStromerArt/index.html)

A website for an artist, built with HTML, CSS and Bootstrap. It presents her art, exhibitions and a form for signing up to art classes.

### [Flashcards](https://joystromer.github.io/portfolio/Flashcards/index.html)

My first JavaScript project: a flashcard app where users create and delete cards, saved in LocalStorage.
