## Flashcards

My first JavaScript project created at University West: A flashcard app.

[Open the page](https://joystromer.github.io/portfolio/Flashcards/index.html)

### What the page is about

A flashcard app where the user writes a question and an answer to create a card. All cards are saved in the browser, so they are still there when the user returns to the page.

### Features

- Create flashcards with a question and an answer
- Show and hide the answer on each card
- Delete individual cards

### What I practiced

- DOM manipulation: creating, updating and removing elements with JavaScript
- Event listeners for buttons and user actions
- Saving data in LocalStorage and converting it with `JSON.stringify` and `JSON.parse`
- Storing cards as objects in an array, each with a unique ID (`Date.now()`)
- Using array methods such as `forEach` and `filter`
