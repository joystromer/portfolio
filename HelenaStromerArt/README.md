## Ramverk - a web page for an artist

I created this web page using the framework (Ramverk in Swedish) with Bootstrap.

[Open the page](https://joystromer.github.io/portfolio/Ramverk/artclasses.html)

My mom is an artist and I built this web page for her, inspired by her art. 
This was during the time I studied the program Webmaster at University West in Sweden. 

### What the page is about

The page presents my mom and her art. It includes a portfolio with images of her
work, a section on her previous and upcoming exhibitions, and a form where people
can sign up for her art classes.

The page is responsive. It currently uses placeholder text and images.

### Built with

- HTML
- CSS
- Bootstrap 5 (layout and navigation)
- Bootstrap Icons
